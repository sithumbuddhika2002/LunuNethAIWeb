Methodology & Technologies

The LunuNeth AI platform follows an Iterative Developmental Life Cycle (Agile Methodology), architected as a modular, consolidated microservices framework for high scalability and sub-second inference. Each specialized agricultural AI module operates independently while communicating seamlessly through an asynchronous RESTful API layer and centralized cloud data persistence.

Iterative Agile Cycle

Continuous bi-weekly sprints, field data annotation loops, and direct feedback from Mahailluppallama agricultural extension officers.

Consolidated Microservices

Independent containerized FastAPI endpoints coordinating PyTorch, TensorFlow, and GraphSAGE backends asynchronously.

Edge & Cloud Hybrid Resilience

On-device quantized TinyML for instant field feedback alongside cloud ST-GNN forecasting and MongoDB Atlas history synchronization.
