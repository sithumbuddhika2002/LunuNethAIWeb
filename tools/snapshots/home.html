Intelligent Crop Protection Modules

Our unified platform hosts advanced deep learning pipelines to keep onion farms healthy, productive, and sustainable.

Onion Leaf Classifier

Diagnoses severe diseases like Purple Blotch and Leaf Twist Disease (LTD) using quantized MobileNet/TFLite models directly on-device.

Thrips Pest Detector

Detects and labels onion thrips pests in real-time. Uses PyTorch Faster R-CNN target localization with visual bounding boxes.

Nutrient deficiency

Identifies Nitrogen (N), Phosphorus (P), and Potassium (K) deficiencies, projecting Grad-CAM heatmaps showing exact symptom focus.

AgriBot Chat Advisor

Combines NLP BERT classification and Bayesian decision trees to interview users, delivering crop remedy recommendations.

ST-GNN Outbreak Forecast

A Spatio-Temporal Graph Neural Network predicting region-wide disease spread by modeling spatial relations between adjacent farms.

Multi-Agent Backend

FastAPI asynchronous backend with isolated microservices, Docker Hugging Face Space deployments, and unified MongoDB clustering.

Unified Platform Architecture

A decoupled multi-agent architecture bridging mobile clients and scalable cloud deep learning services.

Flutter Client App

Cross-platform UI (iOS/Android), offline sqlite caching, camera scan interfaces, and light TFLite classification.

FastAPI Router Server

Docker container hosting on Hugging Face Spaces. Multi-agent coordination, database clustering, and async processing.

DL Inference Pipelines

PyTorch object detectors, EfficientNet Grad-CAM, BERT classification engines, and ST-GNN crop spread forecasting.
